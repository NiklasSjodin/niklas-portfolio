# Niklas — Portfolio

Personal developer portfolio built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Stack

- Next.js (App Router)
- TypeScript (strict mode)
- Tailwind CSS
- ESLint
- Lucide icons
- npm

## Getting started

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command         | Description                          |
| --------------- | ------------------------------------ |
| `npm run dev`   | Start the local development server   |
| `npm run build` | Create a production build            |
| `npm run start` | Serve the production build           |
| `npm run lint`  | Run ESLint                           |

## Project structure

- `src/app` — routes and root layout
- `src/components` — reusable UI (`Container`, `Button`, `Section`, navigation)
- `src/lib` — shared constants (navigation)

No database, CMS, authentication, or backend API is included.
